🏠 KushMap - Home Designer
==========================

A simple house layout designer using Python and Pygame.

---

🧰 Requirements
---------------
- Python 3.8 or later
- Pygame library

---

🚀 How to Run
-------------
1. **Install Python**
   - Download from: https://www.python.org/downloads/
   - During installation, make sure to check “Add Python to PATH”

2. **Open Command Prompt**
   - Press `Win + R`, type `cmd`, and press Enter

3. **Install Required Package**
   Run this command:

   pip install pygame

4. **Run the Script**
   Navigate to the folder containing `kushmap.py`, then run:

   python kushmap.py


✨ Enjoy designing your dream floorplans!
